Calculation and scope

Origin O = Stick Out for Stock front; O = Stick Out − Front stock for Model front. Initial finished face F = Stick Out − Front stock. Sub jaw face at grab J = O + Grab Plane. Actual grip = F − J. Pull = Return Plane − Grab Plane. Final finished face = F + Pull.

From physical values: Grab Plane = F − grip − O; Return Plane = requested protrusion − grip − O. Both pairs describe the same transfer. A zero-return replacement is shown explicitly; it can make the actual result differ from the requested value.

The main chuck face is at −main jaw length. At machine return the sub jaw face is at chuck distance − main jaw length − sub jaw length. This geometry fixes the scale and limits the supported range. B0 still places the sub jaw face at G54 Z0, not machine home.

v1.1 scope: grab → pull with uncut bar → main closes → cut-off status. No cut-off location, detached part length, G28 G53 return movement or G55 calculation yet.
