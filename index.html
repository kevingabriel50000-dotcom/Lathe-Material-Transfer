Cómo se calcula

Origen físico O = salida inicial del stock para Stock front; para Model front, O = salida inicial − material frontal retirado. Cara terminada inicial F = stock − desbaste. Jaws del sub en grab J = O + Bgrab. Agarre real = F − J. Pull = Bdestino − Bgrab. Cara final = F + pull.

En modo resultado físico: Bgrab = F − agarre − O; Bdestino = salida deseada − agarre − O. El sustituto de cero se aplica únicamente cuando el destino calculado es cero.

Alcance v1.0: grab → pull con barra unida → main cierra → cut-off. El retorno a máquina G28 G53 y el origen G55 todavía no se modelan. No genera código CNC ni valida colisiones, sincronización o condiciones de mecanizado.
